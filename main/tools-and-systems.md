# tools-and-systems.md

## Stack Principal

| Ferramenta | Uso |
|---|---|
| **Confluence** | Documentação dos projetos — fonte de verdade para estados, decisões e informação relevante |
| **Jira** | Tracking de tarefas e gestão de Sprints (Sprints geridos pelos POs) |
| **Microsoft Teams** | Chat e reuniões online |
| **Outlook** | Email |
| **Notepad++** | Notas pessoais e registo durante reuniões, quase sempre em formato Markdown |

## Onde vive a informação

- Documentação dos projetos: **Confluence**
- Gestão de trabalho: **Jira**
- Notas pessoais e rascunhos: **Notepad++** (Markdown)
